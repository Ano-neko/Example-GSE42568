# Delivery acceptance and project structure

## Release decision

**Accepted for v1 delivery: PASS WITH DOCUMENTED LIMITATIONS.** The bounded processed-expression workflow completed without a scientific hard stop. The formal cancer-minus-normal design status is Green; 32/32 Scientific QA checks, 13/13 reproducibility guards and 10/10 clean-rebuild key-file comparisons passed.

This acceptance applies to the frozen scope in `GSE42568_PROJECT_DESIGN.md`. It does not extend the result to diagnosis, prognosis, treatment response, causal interpretation or the explicitly excluded WGCNA, survival, machine-learning, immune-infiltration and drug-prediction modules.

## Verified release facts

- Official GSE42568 processed matrix: 54,675 probe sets by 121 samples; 104 cancer and 17 normal; zero non-finite values.
- Primary run-adjusted P1 analysis: 20,357 tested Entrez genes, 5,381 moderated-BH discoveries and 2,835 TREAT 1.2-fold priorities (1,497 cancer-up; 1,338 normal-up).
- Sensitivity: every P1 priority direction is concordant in S1, S2, the QC-candidate exclusion analysis, no-trend analysis, group-aware collapse and all 13 leave-one-run-out fits. Median-collapse priority concordance is 97.0%, with 84 reversals retained as gene-level cautions.
- Enrichment: GO BP/CC/MF ORA and Reactome ORA/GSEA completed with resource-specific tested backgrounds; the GSEA ranking is all 20,357 P1 moderated t statistics. KEGG and MSigDB Hallmark remain explicit licence-gate rows and were not accessed.
- Rebuild: starting from the two checksum-locked official GEO downloads, 10/10 key tables reproduced byte-for-byte in 5 minutes 16 seconds on the verified server.
- Reports: client report 11 pages, methods appendix 5 pages and QC appendix 10 pages; all pages were rendered and visually reviewed, with no blank, clipped or overlapping pages.
- Full-workspace integrity: the machine-readable manifest is valid JSON and every row in its final checksum ledger verifies. These inventories describe the complete local analysis workspace and are intentionally omitted from the public portfolio edition.

## Directory map

| Path | Purpose | Version-control policy |
|---|---|---|
| `R/` | Stage implementations: acquisition/validation, QC/annotation, signed sample review, DE/sensitivity, enrichment and Scientific QA | Track |
| `scripts/` | Download, acceptance runner, report builder, environment capture and release finalizer | Track |

| `results/tables/` | Statistical results and QA ledgers | Track key/compact tables; omit regenerable `figure_*_source.tsv` and the local 116 MB GO TSV |
| `results/figures/` | F01-F15 analysis figures and associated release formats | Track |
| `reports/` | Markdown/HTML reports and R session information | Track |
| `output/pdf/` | Final client, methods and QC PDF deliverables | Track |
| `docs/` | QA, decisions, limitations, implementation notes and rebuild evidence | Track |
| `tests/` | Synthetic and schema/reproducibility guards | Track |
| `tmp/` and `results/logs/` | Runtime-only workspace and run-specific logs | Ignore; regenerated by the runner |
| `machine_readable_manifest.json`, `results/checksums/` | Complete-local-workspace inventory | Omit from public edition; use its separate acceptance ledger |
| `config/environment.yml`, `config/conda-explicit-linux-64.txt` | Pinned cross-machine and exact Linux Conda environments | Track; these are the reproducibility source of truth |

No other unignored release file exceeds 90 MB.

## Residual limitations accepted for v1

Normal-tissue provenance, normal ages and pairing are unavailable; the processing-run proxy is partially confounded with tissue group; the data are processed-only and therefore lack CEL-level QC; bulk-tissue composition and cancer heterogeneity remain; and there is no external validation cohort. Four unusual but technically plausible samples remain in P1 and are excluded jointly only in a named influence analysis.
